# 我的价值取向与下注宪法（v1.0）

> **AI 必读**：任何投资/创业/重仓建议之前，先读本文并引用条款编号；不确定标 UNVERIFIED；不得替我下注。

## 零、一句话

我的第一目标不是赢最多，是**不输光**。任何机会必须先证明“最坏情况下我还活着”，再谈收益。

## 一、三条铁律（不可协商）

| # | 铁律 | 含义 |
|---|---|---|
| 1 | 单笔最大损失 ≤ 总资金 5% | 亏光这一笔，不影响下一次下注 |
| 2 | 单一赛道 ≤ 20% | 不把命运押在一个政策/客户/模型上 |
| 3 | 没有退出路径的不投 | 说不清“怎么撤、撤了剩什么”，直接否 |

## 二、五维环境检查（1–5 分）

| 维度 | 看什么 | 低分信号 |
|---|---|---|
| 国情 | 国产替代、政策连续性、地方执行 | 政策一年三变 |
| 政治 | 中美关系、出口管制、数据主权 | 依赖单一海外供应链 |
| 供需 | 算力/人才/客户 | 供给过剩、价格战 |
| 市场 | 付费意愿、客单价、复购 | 只有免费用户 |
| 监管 | 牌照、备案、数据合规 | 需要资质且我们没有 |

**红线**：任一维 ≤2 分不投；总分 <15/25 只观察。

## 三、四层分析（缺一层不算完成）

1. 事实层：数字、时间线、原文、来源级别
2. 叙事层：潜台词、时代脉络、生态位
3. 方法论层：奥德赛、5/10 年、奥卡姆、压力测试、负面清单
4. 代价层：资金、时间、退出、合规、声誉

## 四、代价清单（必须写）

| 类型 | 必须回答 |
|---|---|
| 资金 | 最多亏多少？多久回本？ |
| 时间 | 投入几个月？机会成本？ |
| 退出 | 最坏怎么退？退了剩什么？ |
| 合规 | 需要什么资质？没有会怎样？ |
| 声誉 | 失败是否影响长期信用？ |

## 五、下注规则

- 首笔 ≤5%，跑 3 个月看锚点
- 锚点命中 ≥2 个，才加到 20%
- 触发止损无条件退出，不摊平、不解释
- 不杠杆、不 all-in、不借钱
- 实际仓位 = 半凯利 × 0.5（保守系数）

## 六、负面清单（直接不做）

1. 说不清靠什么赚钱的
2. 需要牌照但我们没有的
3. 赌政策放松/监管套利的
4. 因为别人都在做才做的
5. 无法退出的
6. 补贴停就死的
7. 需要 all-in 才成立的

## 七、决策流程（七步）

信息 → 四层分析 → 五维评分 → 代价清单 → 仓位建议 → 最坏情况 → 下注/观察/放弃。

任一步缺证据，结论只能是“观察”。

## 八、复盘机制

- 每条预测进「预测台账」，带概率与截止日
- 月度结算命中率与 Brier 分
- 季度复盘：命中率 <60% 的策略降级或停用
- 失败案例必须写“当时忽略了哪一维”

## 九、AI 交接协议

1. 建议前先读本文，引用条款编号
2. 不确定标 UNVERIFIED
3. 不得替我下注，只给“建议仓位 + 最坏情况”
4. 建议必须含五维评分、代价、退出路径
5. 触发铁律时直接说“不能做”，不得软化

## 十、版本与修改

只增不删；修改写“为什么改”；季度复审；重大亏损后 7 天内强制复审。
