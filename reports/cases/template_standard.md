# 标准模板 · 大厂生态位尽调（2026-11-20）

> 用途：统一 WorkBuddy / DSH / OpenAI / Anthropic / 豆包 等案例的写法。所有版本并联保留，只增不删。

## 一、四个版本，各答一个问题

| 版本 | 回答 | 形态 |
|---|---|---|
| V1 | 它是什么、值不值 | 事实单页：指标/沿革/A·B 面/风险/评分/可推翻 |
| V2 | 它为什么这样、站在哪 | 三层叙事：前置事实 + 潜台词/生态位 + 方法论 |
| V3 | 我该站哪、抄什么 | 生态位判断：食物链/天敌/可抄/门槛/复利/套利 |
| V4 | 全量合并 | 以上 + 心路历程 + 关键表态 + 安全赤裸版 + 未来锚点 |

## 二、三个问题（答完即止）

1. 它靠什么赢？
2. 我能抄哪一块？
3. 我什么时候撤？

## 三、三条红线（触线即否）

- 证据不可核
- 不可替代性为零
- 退出成本过高

## 四、必备章节（V4）

1. 一句话 + 预期差
2. 事实与指标（每个数字带级别）
3. 成本结构
4. 心路历程（决策点 + 事后判断）
5. 关键表态（原文引用，标 A/B/C）
6. A 面 / B 面
7. 安全与治理赤裸版（官方原文 + 取舍分析）
8. 风险 R1–R6（触发/后果/证据）
9. 生态联动
10. 赌注与利益结构
11. 叙事：潜台词/时代/生态位/阶级/反事实
12. 食物链动物图谱
13. 可抄/门槛/复利/套利
14. 方法论：奥德赛/5·10 年/奥卡姆/压力测试/负面清单/官方手段/用户做法
15. 未来三情景 + 观察锚点
16. 评分（红杉含平台/剥离、浑水、压力测试、Nature 自评）
17. 可推翻条件 + 版本 + 缺口

## 五、动物图谱（固定）

鲸鱼（模型/算力）→ 鲨鱼（成品 Agent）→ 珊瑚礁（平台）→ 小丑鱼（垂直应用）→ 䲟鱼（套利）→ 寄居蟹（我方：借壳、换壳、不造壳）。

## 六、评分锚点

| 口径 | 看什么 |
|---|---|
| 红杉（含平台） | 市场/时机/壁垒/单位经济/团队 |
| 红杉（剥离平台） | 去掉分发与补贴后还剩什么 |
| 浑水 | 证据能否复算、是否有利益冲突 |
| 压力测试 | 最坏情景下结论是否成立 |
| Nature | 原创/证据/可复现/不确定度/替代解释/局限/COI/独立验证/更正 |

## 七、更新机制

- 每月看锚点 1/2/4，每季看 3/5/6
- 触发即出新版；旧版只读
- 结论变化 ≥2 分必须写“改判理由”
- 任何版本先落本地 md，再上飞书

## 八、禁止事项

- 不删旧版、不覆盖
- 不编数字；缺就写 UNVERIFIED
- 不把预测写成事实
- 不把“官方口径”当“审计结论”
