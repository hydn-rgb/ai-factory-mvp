# 叙事 · DeepSeek Harness（DSH）

> 2026-11-20 · v1.0 · 事实与推断分开标注：`[A]` 官方 ｜ `[B]` 主流媒体 ｜ `[C]` 社区 ｜ `[推断]` 本报告

## 一、潜台词

官方说「Agent = Model + Harness」——模型负责想，外壳负责做。

潜台词是：**模型会越来越便宜、越来越像水电，真正值钱的是“谁来当那个外壳”**。DSH 不做模型，做模型外面那一层：工具、权限、沙盒、会话、插件、UI。谁占了这层，谁就掌握了“模型怎么被使用”的定义权。

它不是在做一个工具，是在抢**Agent 时代的默认运行时**。

## 二、时代脉络

三个条件同时到位，才有 DSH：

1. **模型降价**：DeepSeek 自己把 token 价格打下来，能力开始平权。
2. **Agent 认知成熟**：Claude Code / Codex 让“AI 能动手”变成常识。
3. **入口开放**：桌面端、IM、插件机制都能被第三方接入。

再叠加一个文化条件：**开发者注意力在 B 站**。DSH 把官宣、长文、插件作者故事都放在那里，等于直接在“开发者集市”摆摊。

## 三、生态位 · 过去

在它之前，Agent 是**整包**：Cursor、Claude Code、Codex，开箱即用，但不可拆。

整包模式的问题：模型换了、工具换了、审批策略想改，用户只能等厂商。DSH 做的事情是把整包拆成零件——模型适配器、工具、沙箱、UI 全是插件，卸载即无残留。

它抢的不是“更好的 Agent”，是**“Agent 应该可以被组装”这个定义**。

## 四、生态位 · 现在

它站在中间层：

```
模型（DeepSeek / 第三方）
        ↑
   DSH（运行时 + 插件系统）
        ↓
插件（3.5 万个）→ 用户（154 万 DAU）
```

- 上：不锁定模型，谁便宜用谁
- 中：用插件数量形成网络效应（60% 活跃用户至少装一个）
- 下：把“开发者的创造力”变成自己的护城河

它的位置很像早期的浏览器：不生产内容，但决定内容怎么被看见。

## 五、生态位 · 未来

两种挤压：

1. **上游挤压**：模型厂把 Agent 能力内置（OpenAI/Anthropic 都在做平台），外壳变得可有可无。
2. **下游逃离**：插件作者长成垂直 App，用户直接买插件，不再感知 DSH。

能不能守住，取决于一件事：**插件作者能不能在 DSH 上赚到钱**。赚不到，3.5 万会变成 3.5 千。

## 六、不同阶级的看法

**老板**：便宜、可控、能私有化；担心插件安全与维护成本。
**打工人**：门槛低、插件多；担心不稳定、破坏性变更。
**开发者**：自由、可改、能靠插件变现；担心平台规则说变就变。
**投资人**：生态势能罕见；但商业化路径没公开，且依附 DeepSeek 的模型与价格。
**监管**：本地优先、白盒日志是加分；插件供应链目前没有统一安检。
**竞品**：成品 Agent 的“整包溢价”被拆穿，用户开始问“为什么不能换外壳”。

## 七、三个转折点

| 时间 | 事件 | 为什么关键 |
|---|---|---|
| 2025-08-13 | 开源 v0.1 | 把“可组装”变成公共品 |
| 2025-09-29 | 桌面端 | 从开发者玩具变成个人电脑里的常驻 |
| 2026-11-02 | B 站官号入驻 | 把开发者社区变成分发渠道 |

## 八、反事实

如果 DSH 没出现：插件生态会散落在各家成品 Agent 里，每个平台一套规则，开发者被锁定，中国 Agent 生态更碎片化。

如果 DSH 出现但插件不赚钱：它会退化成“极客的玩具”，DAU 停在百万级，成为模型厂的附属品。
