# 生态位判断 · DeepSeek Harness（V4.3 标准版）

> 标准模板首篇。级别：`[A]` 官方 ｜ `[B]` 媒体 ｜ `[C]` 社区 ｜ `[推断]`。版本 V4.3，与 V1–V4.2 并联保留。

## 零、一句话

DSH 用“开源 + 插件”换来生态速度，代价是把安全成本整体转嫁给用户；官方自己承认“未审计、不可视为安全或生产可用”。

## 一、事实与指标

2025-08-13 开源，MIT。官方口径：154 万 DAU（仅官方 API 用户）、日耗 92 万亿 token、3.5 万第三方插件、60% 活跃用户装插件（B 站官方公告 200）。GitHub 284,407 stars。

## 二、成本结构

DSH 免费，成本在模型 token、算力、插件兼容维护。对一人公司友好：无最低消费，按量支出；代价是稳定性和运维自己扛。

## 五、A 面

开源可审、白盒日志、本地优先、插件卸载无残留、社区自组织（B 站近半插件作者在分享）。

## 六、安全与治理：赤裸版

官方 SAFETY.md 原文：

> “can execute model-generated code and commands, load third-party plugins, and access the network, processes, credentials, and files made available to it.”

> “Sandboxing, approval prompts, and permission controls can reduce risk, but they do not guarantee isolation or prevent damage.”

> “Do not rely on DeepSeek Harness as the sole security control for untrusted workloads.”

翻成商业语言：插件即任意代码；3.5 万插件无统一审查；沙箱是减害不是隔离；出事作者不负责（MIT）。

这是取舍，不是疏忽：治理后置、不分层背书、安检缺位、测试外包给社区——用“不设门槛”换生态速度。

## 八、生态联动

接 DeepSeek 模型/API，下接插件市场，外借 B 站社区。冷启动快；但增长难与“模型热度”剥离。

## 十、叙事与生态位

潜台词：赌“谁来当外壳”。时代：降价 + Agent 认知 + 入口开放 + B 站注意力。生态位：过去替代整包，现在占中间层，未来被上下游夹击。

各阶级：老板看成本；开发者看自由；投资人看生态；监管看供应链；竞品看整包溢价被拆。

反事实：没有它，插件生态碎片化；一次插件投毒，信任归零。

## 十一、食物链动物图谱

鲸鱼（模型/算力）→ 鲨鱼（成品 Agent）→ 珊瑚礁（DSH）→ 小丑鱼（垂直插件）→ 䲟鱼（套利）→ **寄居蟹（我方：借壳、换壳、不造壳）**。

## 十二、可抄 / 门槛 / 复利 / 套利

可抄：插件形态、开放接口、社区内容、低价模型+高价交付、垂直按结果收费。
门槛：分发、算力、信任、合规。
复利：数据、插件量、品牌；模型能力不成立。
套利：模型价差、信息差、时间差、生态差。

## 十三、方法论

奥德赛 A/B/C → 选 B。5 年：运行时被吸收；10 年：标准制定者赢。奥卡姆：不自建 runtime。压力测试四场景不改 B。负面清单：不做通用运行时、不做无安检插件市场、不绑 preview、不追 star。官方手段：治理后置/不分层背书/安检缺位/测试外包。用户做法：白/灰/黑/红/紫。
