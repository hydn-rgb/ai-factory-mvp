## V1 · 事实单页

### 1. 一句话 + 预期差

一句话：机构A是中国唯一曾破千亿的量化私募，实控人把算力与模型做成第二主业（DeepSeek），用"低估值/低成本"改变 AI 竞争。
预期差：公众把它当"量化公司顺便做 AI"，**公开事实更像是把 AI 当成基础设施与长期赌注，资管规模反而主动收缩**；对我方而言，可抄的是流程与纪律，不是规模。

### 3. 成本结构

- 算力：萤火一号 ~2 亿 → 萤火二号 ~10 亿（B）；这是不可复制的门槛。
- 模型训练：V3 约 557 万美元（B，不含存量算力/人力）。
- 组织：量化资管现金流 + AI 长期投入；短期不融资（B）。
- 我方成本：信源探针 + 人工校验 + 插件调用，量级远低；**不比算力，比可复算的留痕**。

### 4. A 面 / B 面

- A 面：技术投入连续、敢于自我蚕食资管规模、低成本模型改变行业定价。
- B 面：规模口径混乱；算力受芯片供给约束；高收益数字难独立复算；AI 叙事容易掩盖资管业务波动。

## V2 · 三层叙事（为什么这样、站在哪）

1. **前置事实**：千亿规模 → 主动收缩 → 算力堆到万卡 → 模型以低价出圈（F2/F4/F7/F10）。
2. **潜台词/生态位**：创始人X不是"用 AI 辅助量化"，而是"用量化现金流供养一个通用 AI 赌注"；[推断] 规模控制在为算力与模型让路，避免资管规模成为约束。
3. **方法论**：把长期不确定赌注拆成可交付版本（算力→模型→产品），并在对外叙事上淡化短期融资/规模目标。

> 反事实：若 2021 年不建万卡集群，DeepSeek 是否还能以同样成本出圈？置信度中低——只能说明"算力是承重墙之一"，不能证明唯一性。

## V4 · 全量合并

### 心路历程（决策点 + 事后判断）

- 决策点 1（~2019–2021）：把资金投入深度学习训练平台 → 事后看是承重墙，但当时无法证明收益。
- 决策点 2（2023）：模型对外亮相，定位低价 → 事后改变行业定价，但属于公开叙事，不能反推"必然赢"。
- 决策点 3（2024）：报道中的规模收缩 → [推断] 主动取舍，尚缺公司公告验证。
- 教训：大赌注的合理性来自"可承受的最坏损失"，不是来自事后成功。

### 关键表态（原文引用）

- 创始人X："大模型业务短期内没有融资计划，面临的问题从来不是钱，而是高端芯片的获取问题。"（B，S1；抓取 2026-11-21 13:45+08:00）
- 行业圆桌："非结构化数据往往存在数据污染、时间错误……必须进行数据清洗、人工校验与结构化处理。"（B，S6）
- 行业圆桌："新模式并非万能，需要经验丰富的人类参与和控制。"（B，S6）

### A 面 / B 面（补充）

A：资源集中、版本快速迭代、低成本路线。B：对单一创始人/算力供给依赖高；公开口径不一致；成功叙事易被过度外推。

### 安全与治理赤裸版

- 官方/公开信息：无外部融资表述（B）、模型训练成本披露（B）。
- 取舍分析：低价模型扩大生态但压缩行业利润；我方不参与价格战，只利用"推理成本下降"降低探针成本。
- 我方治理：所有事实进 A/B/C/D 台账；模型/AI 输出必须经人类复核；密钥不落盘；不碰非公开数据。

### 生态联动

机构A（资管/算力）→ DeepSeek（模型）→ 行业低价竞争 → 我方探针推理成本下降 → 证据台账增厚。机构B的处罚案例（T2）提供反向边界：同行业不同治理结局。

### 赌注与利益结构

- 机构A赌注：算力 + 通用模型；收益来自资管与生态位，不来自卖模型 API 的短期利润（[推断]）。
- 我方赌注：公开证据链 + 可复用插件 + 破产场景线索；最坏损失 = 时间 + 少量 probe 成本；退出成本 = 低（无仓位/无牌照绑定）。

### 叙事：潜台词 / 时代 / 生态位 / 阶级 / 反事实

- 潜台词："先占算力与模型生态位，规模可以让路。"
- 时代：AI 成本快速下降、监管逐步成形的窗口期。
- 生态位：从量化头部迁移到 AI 基础设施玩家，避免只做资管周期。
- 阶级：资本/算力密集层；我方处于借壳层，不共享其利润分配。
- 反事实：若不做 AI，机构A可能仍是头部量化但增长曲线受限（置信度中）。

### 食物链动物图谱

鲸鱼（机构A/DeepSeek：模型+算力）→ 鲨鱼（成品 Agent）→ 珊瑚礁（平台/分发）→ 小丑鱼（垂直应用）→ 䲟鱼（套利：公开信息差）→ **寄居蟹（我方：借壳、换壳、不造壳）**。
