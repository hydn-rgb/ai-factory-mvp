# T19 · 信源合规地图（能抓 / 只能看 / 不能碰）

- 生成: 2026-11-21
- 实测: `reports/compliance/T19_robots_probe.json` + `T19_robots_excerpt.json`（2026-11-21 12:5x）
- 原则: **robots 允许 ≠ 授权批量抓取；公开可看 ≠ 可商业化转售。** 本表只覆盖“破产捡漏”所需公开信息。
- 三层定义:
  - **G 绿（可自动低频抓）**: robots 允许或未限制，页面为公开公告，限速 ≤1 req/3s，保留原始链接与 sha。
  - **Y 黄（只人工看/单篇取用）**: 需登录、验证码、付费墙、或 robots 不明确；不批量下载，但单篇公开页面可作为证据（必须留 URL + 抓取时间 + sha）。
  - **R 红（不碰）**: 明确禁止、需绕过访问控制、含个人信息、或用于骚扰/交易个人信息。

## 二、三条硬规则（写进探针）

1. **不绕访问控制**: 遇到登录、验证码、付费墙、403/412/521，记录“不可达”并停止；不换 IP、不换 UA 伪装、不试密码。
2. **不采个人信息**: 不抓自然人手机号、身份证、住址、债权人名单中的个人信息；只保留公司名/案号/金额。
3. **可复核**: 每条记录保留 `url + 抓取时间 + HTTP 状态 + sha256(前 16 位) + 等级`；无 sha 的一律 `UNVERIFIED`。

## 三、与探针的映射

- `ops/probes/sources.json` 的 `legal` 字段只允许:
  - `public` / `public_readonly` / `authorized` → 可参与评分与证据判定；
  - `paywall` / `login` / `prohibited` / `private` → 一律 `UNVERIFIED`，只能当线索。
- `source_ledger.py` 硬门槛: 来源 D/E、可信度 4–6、`legal` 不在白名单 → 不作证据。
- 探针失败（521/412/超时）自动降为 `UNVERIFIED`，不因“分数高”而放行。

## 四、明确不碰的 5 类

| 类型 | 例子 | 原因 |
|---|---|---|
| 债权人个人信息 | 债权申报表、身份证、银行账号 | 个人信息保护法；与业务无关 |
| 内部文件 | 管理人工作底稿、未公开审计 | 非公开，可能构成内幕信息 |
| 绕验证码/登录 | 裁判文书网强制登录页 | 绕过访问控制 |
| 付费墙正文 | 财新深度稿全文 | 版权 + 条款 |
| 批量转售 | 把公告库做成付费数据源 | 许可不明，先不做 |
