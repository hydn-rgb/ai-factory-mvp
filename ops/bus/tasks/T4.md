# T4 · OpenCode 轻量插件：按会话/任务切换模型与档位

- task_id: T4
- owner: 执行窗口 W4
- parent: W0
- 目标: 一个轻量插件/包装层，根据「会话 + 任务类型」自动选模型与档位，降低无效花费
- 背景: 长会话默认用同一模型，调研/文档/审计都按高价跑，浪费
- 范围（只做这三件）:
  1. **任务分类**：代码 / 调研 / 文档 / 审计（四类，规则可解释）
  2. **模型策略**：默认 DeepSeek flash；重任务升级；离线/隐私任务走本地
  3. **会话覆盖**：手动指定优先，插件只在“未指定”时生效
- 技术路线（按可行性降级，不硬撑）:
  - 首选：OpenCode 插件钩子（`@opencode/plugin`）监听会话/消息事件 → 设置模型
  - 若钩子不支持切模型：退化为「agent 配置 + 命令包装」两层
  - 再不行：只做 `opencode run --model` 包装脚本 + 任务卡提示
- 输入: OpenCode 文档/源码（plugin 接口）、当前 `opencode.json`、`projects` 里的实际任务
- 输出:
  - `D:\AI_Factory\plugins\model_router\`（插件或包装层）
  - `README.md`（怎么装、怎么回滚）
  - `test_log.jsonl`（每次切换：session/task_type/model/reason）
- 验收（机器可判）:
  1. 新建会话 → 日志出现 `task_type` 与 `model`
  2. 手动 `/model` 指定 → 插件不覆盖
  3. 插件异常 → 回退默认模型，不阻塞对话
  4. 回滚：删插件目录 + 重启，行为恢复
- 预算: ¥10 / 3 小时
- 禁止: 不装第三方依赖；不硬编码 key；改配置前必须备份；不改 DSH/WorkBuddy 配置
- 下一步: 无（已归档）
- 回执: `out/T4.json` = {task_id, owner, status, artifact, sha, rows}
